# Luminous RCの照り返しの柔らかさ

関連調査: [3D RCの補間・方向積分・時間蓄積・ringing対策との比較](./radiance-cascades-3d-filtering-research-2026-10-26.md)。本メモは実装と検証結果を扱う。

## 観測と調整対象

所有者から、発光面と距離がある天井・柱の周囲に、くっきりした模様が出るという報告があった。添付は通常MMD / Frame Graph / WebGPU、Luminous RCと通常Luminousの併用で、表示は約19〜20 FPS。別の近接画像では髪にも細かな照射の変化が見える。所有者は最近景cascadeの精度が強すぎる可能性を挙げ、具合を調整したいと依頼した。

現行receiverには32方向の固定gatherと短距離の直接traceがあり、角度の離散化や接触光の細部もくっきりした変化の要因になり得る。画像だけから特定cascadeの精度を原因と確定していない。所有者のモデルは探索・読み込みせず、自作の輪状発光・柱・天井でRC照明の調整を検証した。

## 操作

Luminous RC個体に「RC 柔らかさ」を追加。UIは0〜100、保存値は`fixedSettings.radiance.softness`の0〜1。

- 0: 従来の照明を使い、追加のcompute処理を停止する。旧project・旧RC個体も0で復元する。
- 値を上げる: RC照明の細かな変化を面に沿ってなじませる。強度・範囲は別の入力として保つ。
- 所有者の実シーンでは20〜30で良好との確認を得た。シーンごとの調整の出発点とし、近接部の必要な細部まで薄くなる場合は下げる。初期値は0のままで、全シーン共通の推奨値とはしない。

個体ごとの固定設定として保存・読込・複製・Undo/Redoに含め、backendの往復でも保持する。enabledと同様のキーを新設する変更ではない。5言語のラベルを追加した。

### RC 距離連動（近距離／遠方の近似）

「RC 距離連動」をONにすると、光源に近い照り返しの細部を保ち、遠方の寄与へ「RC 柔らかさ」を適用する。まず柔らかさ20〜30のままON/OFFを比較する。保存値は個体の`fixedSettings.radiance.distanceSoftness`（boolean）。初期値・旧projectの復元はOFFとし、従来の固定ぼかしを維持する。柔らかさ0では距離連動のON/OFFにかかわらず未加工照明になる。設定は保存・読込、複製、Undo/Redo、Classic / Frame Graph往復で保持する。

## 描画処理

[専用shader](../src/render/luminous-radiance-softening.ts)で、receiverの未加工照明から3×3のfilterを5段適用する。sample間隔は1 / 2 / 4 / 8 / 16。前段の結果を次へ渡し、広い範囲を少数の飛び飛びsampleだけで読むことによる複製像を避ける。面を区別した多段filterは[Edge-Avoiding À-Trous Wavelet Transform, HPG 2010](https://diglib.eg.org/handle/10.2312/EGGH.HPG10.067-075)も参照した。本実装は照明の見た目を調整するためのもので、論文全体の再実装ではない。

- receiverが書いたview depth / normalを使い、面からの距離と法線の近さで重みを付ける。共有r16f depthの量子化を許容する。
- 位置復元ではreceiverと同じ全解像度のgeometry画素中心を使う。画面上の距離だけでなく、復元位置の距離も重みに使う。柔らかさ1でbase probeの1セルを目安とする。
- 背景や法線の不連続、離れた平行面を混ぜにくくする。光の明暗自体は保護境界にせず、模様をなじませる対象とする。
- 光だけを処理し、材質色、キャラのtexture、通常2D Luminousには適用しない。
- cascade / trace / 発光RGB専用更新は変更しない。未加工のreceiver履歴とepochを保持し、filter結果をそこへ書き戻さない。柔らかさを変えたときに光場や形状を再計算する必要はない。

filterは長辺640画素以内のreceiver解像度で動く。半精度RGBAのscratchを2枚使い、16:9・640×360では合計約3.5 MiB。0でもスライダー操作時のrebuildを避けるためscratchを準備するが、filterのdispatchは行わない。有効時は毎描画5段のcomputeが増える。追加レイはないがGPU費用が無料という意味ではなく、今回GPU timestampや実シーンの性能差は測っていない。

### 距離連動の処理と費用

既存の短距離traceで求まった発光面までのhit距離を使い、合計照明とは別に「ぼかさず残す近距離光」を集計する。短距離traceの上限を`D = volumeSize / 18`、hit距離を`d`として、保持率は`1 - smoothstep(D * 0.25, D, d)`。近接部は保持し、上限へ近づくほど遠方側へ滑らかに移す。短距離traceを抜けてRC fieldから受け取る寄与は遠方側に含める。

filter初段で合計照明から近距離光を引き、既存5段で遠方側をぼかし、最終段で同じ画素の近距離光を足す。最終合成・材質色・通常2D Luminousは従来と同じ。全体をぼかした後に画素単位で混ぜ戻す方式と違い、近距離の細部が周囲のfilter入力へ混ざることも避ける。

追加レイ・cascade・compute段数は増やさない。近距離光の半精度RGBA履歴を2枚追加し、640×360で約3.5 MiB増える（既存scratchとの合計は約7 MiB）。切替時のrebuildを避けるためOFFでも履歴のメモリは確保する。OFFまたは柔らかさ0では近距離光の追加集計・履歴の読書きを停止する。ON時はreceiverの追加集計または履歴コピー、filter初段の近距離光読み出し、最終段の加算が増える。

未加工の合計照明とepochは従来のまま保持する。近距離光は専用の履歴を同じping-pong順序で使い、距離連動の有効状態が変わった場合はreceiverを再評価する。柔らかさの正値間の変更は光場や近距離光を再計算せず、既存filterの重みだけを更新する。

## 検証

通常光・2D Glowを0にし、配布可能なtofu材質から自作の48分割輪状発光を作った。柱・天井は別の非発光材質。天井内部のreceiver値をGPUから読み戻し、背景や他の面を除いて比較した。shaderが書いた線形照明の指標であり、最終画面のRGBではない。

### 距離連動の追加検証

自作の輪状光源に近接する受け面を追加し、近距離光と遠方光が同じ画面にある状態で比較した。柔らかさ65、未加工照明の75%以上が近距離保持分となる2,013画素では、未加工照明からの絶対差 / 光量が固定ぼかし0.4315、距離連動0.0577となり、近接部の細部が残った。近距離保持分のない遠方の3,707画素では、固定ぼかしとの絶対差 / 光量は約1.7%。合計の未加工照明は両方式で一致し、背景の照明は0だった。これは照明bufferの比較であり、物理的な正解との誤差ではない。PNGでも光源直近の輪郭が残ることを確認した。

柔らかさ0での距離連動切替、固定ぼかしへの復帰はPNGのファイル内容が一致した。光源を移動した後も、履歴を使う結果とreceiverを全再評価した結果のPNGが一致した。GUIでON/OFF、Undo/Redo、柔らかさ30での保存・読込、Classic / Frame Graph往復を確認した。

### 2026-10-26 距離連動の実機比較

所有者から、距離連動を使うより「単に柔らかさでぼかしたほうが無難になじむ」との報告と、同じ視点のOFF / ON比較を得た。添付の20:52:14 / 20:52:17の画面はFrame Graph / WebGPU / WGSL+、通常LuminousとRCを併用し、RC強度18・範囲UI 0・柔らかさ38、停止位置0 / 6564。1枚目は距離連動OFF、2枚目はONだった。

OFFでは天井の照り返しがなじみ、ONでは柱の周囲に輪状の細かな模様が残っている。このシーンでは固定ぼかしのほうが所有者の望むルックに合うという実機評価として記録する。表示22 / 21 FPSの単一画面から速度差は判断しない。

比較したUIは距離連動であり、[Hermite補間](./luminous-radiance-hermite-interpolation-2026-10-26.md)のON / OFF比較ではない。近接部を残す仕組みが自作fixtureで動くことと、実シーンの見た目が改善することを分けて評価する。この報告から距離連動の全面撤去やHermiteの採否は推定しない。今回は実機結果の記録のみで、描画・初期値・保存値を変更していない。文書のリンク・差分を確認し、npmの検証は追加実行しない。

## 限界

面光源の物理的な大きさや、光源からの距離に応じた積分を再計算する機能ではない。固定方向の不足そのものや、cascadeの角度・空間解像度は残る。面を区別しても同一面上の遮蔽境界は柔らかくなり得る。r16f depthで区別できない薄い面や、解像度以下の細い形状も完全には保護できない。5段の有限のsample範囲があるため、任意の距離・表示倍率で同じ物理半径を保証しない。

距離連動は短距離の光を保持する近似であり、遠方の光源までの距離をRC全段で追跡する方式ではない。遠方同士では距離によるぼかしの差を付けない。近距離／遠方の区切りは既存のtrace範囲に従い、RC範囲や発光面全体の大きさでも変わる。物理的な光源サイズ・遮蔽物との距離から半影幅を算出する機能ではない。所有者の上記実シーンでは固定ぼかしのほうがなじむとの評価を得た。距離連動の速度差は未計測。
