# MCPのPNG連番出力

既存の別ウィンドウPNG exporterを利用し、`exportPngSequence`をUI operationへ追加する。素材差替えは後続の別トピックとし、統合済みモデルモーションの復元情報不足と分けて扱う。

出力は明示された新規フォルダーのみ。親フォルダーは存在する必要があり、既存フォルダーへの上書き・追記はしない。現在の出力範囲・サイズ・精度・透過設定を利用し、出力条件は既存editor optionsで確認する。最大10000枚。

範囲はGUI共通処理でタイムライン上限内に補正する。設定後に `mmd_get_editor_options` で実際の範囲を確認する。起動前の拒否では終端progressの枚数情報がない場合がある。

main側で編集許可、exporterの所有者、保存先、予定ファイル名を照合する。各PNGは排他的に作成し、既存ファイルを上書きしない。モデルは別rendererがローカルで読み込み、モデル本体やPNG bytesはMCPへ返さない。

進捗と終端結果を分離する。saved/totalだけでは成功とせず、mainで予定数の保存を確認する。取消は当該MCP jobのexporterを閉じ、処理中の書込を待ってから結果を通知する。保存済みファイルと空の出力フォルダーは失敗時も残す。書込中の一部ファイルが残る可能性があるため、失敗/取消時の結果には保存先と保存済み枚数を示す。

素材差替えについては、音声・背景・環境・LUTは既存のloadAssetが現在値を置き換える。モデル/アクセサリや統合済みモーションの差替えにはキーや親参照の移行規則が必要で、単純な削除＋追加を差替えとして公開しない。
