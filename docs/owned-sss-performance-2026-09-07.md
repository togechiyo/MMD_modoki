# 独自SSSの見た目を保つ負荷軽減（2026-09-07）

## 要望と範囲

所有者から、採用済みのSkin / Waxは見た目がよいが実機で20 FPS台になり、見た目を維持して負荷を下げたいとの依頼。比較基準は[最終ルック](./owned-sss-development-2026-09-06.md)。解像度、半径、サンプル位置、色、受光倍率、合成率を変更せず、現在フレームの影更新後にSSSを描く順序も維持した。

## 変更

- 位置・法線・厚みentryの補助パスは、色の照明計算に入る前に必要な出力を返す。clip plane、normal/bump、早期alpha testはその前に実行済み。遅延alpha testやPREPASS/OITでは従来の末尾捕捉へ戻し、透明度判定や複数出力の契約を省略しない。
- 密なGaussian blurは、各tapの指数関数を乗算による漸化式に置き換えた。横・縦の全tap、面ID・法線・接平面距離の判定、隠れたsampleの中心色補充、正規化は維持する。極小の投影サイズで初期重みがunderflowし得る場合は直接指数計算に戻し、NaNを避ける。
- CPUで現在の変形位置を取得する際、影響値0のモーフを先に除き、有効な位置モーフの配列を一度だけ取得する。全頂点×全モーフの走査を避ける。適用順、元配列の丸め、morph後に骨変形する順序は保持し、骨変形は導入済みBabylonの処理を使う。前フレームのposeやboundsを再利用しない。

導入済みBabylon.js 9.2.0の`default.fragment.js`、`abstractMesh.js`の`ApplyMorph` / `getPositionData`、`EngineInstrumentation`を実コードで照合した。ライブラリ更新時は注入位置、alpha判定の位置、morphの丸め・順序を再確認する。

## 計測

許可済みAliciaを使用。全材質へ対象presetを適用、1920×1080、正面、物理OFF、30フレームwarm-up後120フレームの平均。比較画像の通常試験では従来どおり肌材質だけに適用する。数値はこの実機・このシーンでの値であり、20 FPS台という所有者のシーンそのものは再現できていない。

| 項目 | 変更前 | 最終版 |
| --- | ---: | ---: |
| Standardフレーム時間 | 16.67ms | 16.65ms |
| Skinフレーム時間 | 18.98ms（約52.7 FPS） | 17.20ms（約58.1 FPS） |
| Waxフレーム時間 | 18.59ms（約53.8 FPS） | 16.94ms（約59.0 FPS） |
| Skin CPU描画時間 | 12.66ms | 11.99ms |
| Wax CPU描画時間 | 12.34ms | 11.81ms |
| Skin Babylon頂点取得時間 | 3.09ms | 2.45ms |
| Wax Babylon頂点取得時間 | 2.90ms | 2.49ms |

フレーム時間は約9%短縮。別runでは16.6〜16.9msに達したが、約60Hzのフレーム間隔と実行間の揺れがあるので、上表は最終版の実測を採用する。GPU timestampはこの実行環境では取得できず`null`。GPU単独の所要時間やノートPCでのFPSは断定しない。CPU描画時間はsceneのbefore/after render間であり物理など先行observerを含む全CPUフレームではない。頂点取得時間はBabylon呼出し部分で、新helper内の事前モーフ処理はCPU描画時間に含まれる。

再計測は`MMD_MODOKI_SSS_ALICIA=1`、`MMD_MODOKI_SSS_PERFORMANCE=1`、`MMD_MODOKI_SSS_PERFORMANCE_ALL=1`を指定して`npm.cmd run test:e2e -- owned-sss.spec.mjs`。Aliciaが未配置ならskipする。GPU計測はsandbox外のローカル実行。120サンプルのため、性能値をCIの固定assertにはしない。

## 見た目・回帰確認

- Skin / Waxの近接正面・側面を比較。約1300×730の各RGBA画像全体で変化した色成分は15・52・13・79個、いずれも8bitで最大1段階。目視で血色、顔の陰影、ぼけ足が維持されていることを確認。遠景や逆光の境界では少数の画素により大きな差があり、完全なbit一致ではない。
- FrameGraphの遮蔽box・固定面の重なり・ボーン上下移動、Classicの青Toon・ボーン上下移動を確認。現在フレームの影同期、SkinのToon無視、WaxのToon色、PNG・保存復元・解除に成功。
- Aliciaの固定カメラ・腕回転・ルート上下移動と近接PNGを確認。ユーザーの物理つきVMDを読み込んだ検証ではない。
- 単体テスト103ファイル598件、lint、critical型検査成功。通常型検査は既存539件のまま。

### 既存試験の照明基準の更新

ジャンプ試験の単一画素最大差0.03、面重なりの最大差0.11は、採用済みの照明120相当・角度補正より前の値だった。早期終了、漸化式、有効モーフ選別を外した比較元でも、それぞれ0.069580078125、0.171875となることを確認した。軽量化が原因ではない。

そのためジャンプの局所最大差は0.08未満へ更新し、平均0.001未満と同frameの影同期を維持。面重なりの局所最大差は0.18未満へ更新し、平均は既存0.011から0.005未満へ厳しくした（比較元の平均0.004201）。最適化後もこれらを通る。スクリーン空間の面境界に依存する少数画素の差は残る。

比較画像・計測JSONはignoredな`local-references/`に保存。最適化後の所有者シーンでのFPSと見た目は実機確認待ち。
