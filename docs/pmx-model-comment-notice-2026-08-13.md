# PMX モデルコメント通知 2026-08-13

## 目的

MMD 本家が PMX / PMD 読み込み前に表示するモデル情報と読み込み確認を、ビューポート内パネルとして提示する。

## 仕様

- ユーザーが PMX / PMD をファイル選択またはドロップで指定した時点で、モデル本体を構築する前にビューポート左下へ表示する。
- タイトルには PMX / PMD ヘッダーのモデル名、本文にはモデルコメントを使用する。
- 日本語 UI などでは通常フィールド、英語 UI では英語フィールドを優先し、空の場合はもう一方へフォールバックする。
- `OK` で本読み込みへ進む。`キャンセル`、右上の閉じるボタン、Esc では読み込まない。
- パネルは無彩色のグレー枠とし、主要操作の `OK` だけダークグレー塗り・白文字・アプリのキーカラーであるピンク枠にする。
- モデル名はアクセント色を付けず、白い太字で表示する。
- 判断前に消えないよう、自動クローズは行わない。
- 本文の行数に応じてパネルの縦幅を広げる。ビューポートの 68% または 540px を上限とし、それを超える長文は通知内でスクロールできる。改行はモデルコメントの内容を維持する。
- コメントが空でもモデル名と形式・バージョンを提示し、読み込み確認を行う。
- モデル選択を切り替えただけでは再表示しない。
- プロジェクト復元と画像・動画出力用の内部読み込みでは確認を挟まない。
- exporter mode / PNG capture mode では表示せず、画像・動画出力へ混入させない。

## 実装

- main process で PMX / PMD ヘッダーを事前解析し、モデル名、コメント、形式、バージョンだけを renderer へ渡す。
- `OK` が返るまで `MmdManager.loadPMX()` は呼ばないため、キャンセル時はモデル、材質、物理を構築しない。
- 確認結果、閉じる操作、言語選択は `ModelCommentNoticeController` に局所化する。
- コメントは `textContent` で設定し、モデルファイル内文字列を HTML として解釈しない。
