# RC GI・天空遮蔽を併用したダンス再生の負荷軽減

2026-11-03。RC GI と RC 天空遮蔽を有効にしたダンス再生で、所有者の画面では9 FPSまで落ちた。骨とモーフが動く検証シーンで調べると、2効果のCPU側の形状更新に1フレームあたり17.83 ms（中央値）かかっていた。姿勢だけが変わるフレームの形状更新を軽くした。

## どの計算を再利用するか

- 変形前の頂点・ボーンウェイト・モーフ頂点と、毎フレーム動く骨行列・モーフ適用量を別々に記録する。姿勢が進んでも、大きな頂点配列は値が一致すれば前回の記録を使える。三角形インデックスも元の16 / 32ビット整数のまま保持する。配列を直接書き換える編集は値の比較で検出する。
- 頂点位置やワールド変換だけが変わったメッシュでは、前回の三角形データから各頂点のXYZを更新する。UV、テクスチャとその変換、色、材質が使う面の範囲、インデックスを照合してこの経路を選ぶ。姿勢と材質が同時に変われば全項目を詰め直す。色だけを変えた場合は既存のRGB更新を使う。
- 光線の交差判定に使うメッシュ単位のBVHも、位置だけの更新では9座標を検証・転記して境界を再計算する。三角形の並び・走査順・GPU転送範囲は全項目を更新した場合と一致する。各効果は自分の材質情報と計算範囲を使い、再生中もそのフレームの照明を描画する。

## 連続再生の測定

Windows、NVIDIA Ampere、Electron 40.4.1、Babylon.js 9.2.0、WebGPU、1280×720。36三角形の自作PMXにGUIでボーンキーを登録し、再生クロックで32,768三角形の骨・モーフ付きメッシュも動かした。静止ステージは18,432三角形で、両効果の対象は各51,236三角形。カメラと照明範囲を固定し、物理と通常の影はOFFにした。比較元は `8d285b1` のRC処理で、同じ計測コードを使用した。

各条件で別のElectronを起動し、再生ボタンを押して12フレームのウォームアップ後に通常描画80フレームを計測した。FPSは平均フレーム間隔の逆数。実時間再生なので速く描けた側と遅い側では80フレーム中に進むモーション時間が異なる。画像は停止後に同じフレームへシークして比較した。

| 指標 | 変更前 | 変更後（1回目） | 変更後（再計測） |
| --- | ---: | ---: | ---: |
| 両効果ONの平均FPS | 35.7 | 43.5 | 36.7 |
| フレーム間隔の95パーセンタイル | 39.50 ms | 28.20 ms | 36.16 ms |
| CPUフレーム時間の中央値 | 22.65 ms | 18.73 ms | 21.10 ms |
| うちRC形状更新の中央値 | 17.83 ms | 14.20 ms | 16.03 ms |
| うちBVH更新の中央値 | 6.23 ms | 3.50 ms | 3.41 ms |
| GPU描画・計算パスの合計時間の中央値 | 6.92 ms | 6.72 ms | 6.90 ms |
| 両効果OFFの平均FPS | 60.0 | 60.0 | 59.3 |

変更後の2回でBVH更新の短縮幅は約2.7〜2.8 msだった。フレーム全体の所要時間には実行ごとの差がある。80フレーム中のGPU計算は前後とも960回、形状データ等の転送は566,461,440バイトだった。検証シーンで短縮できたのは主にCPU側の準備時間で、動くメッシュの転送と2効果の光場計算には引き続き費用がかかる。

## 所有者の実機での再生結果

2026-11-03、所有者がRC GIとRC天空遮蔽を併用した同じダンスプロジェクトで再確認したところ、再生中のFPS表示は **9 → 13 FPS** に向上した。表示値から換算すると1フレーム約111 → 77 msで、約34 msの短縮に相当する。実機で確認したのは再生全体のFPSで、処理別の時間は上の自作シーンで計測した。

## 画像と回帰確認

両効果ONとOFFそれぞれで、停止して0 → 60 → 0フレームのPNGを出力した。計6枚は変更前後でファイルのSHA-256まで一致した。ONでは0と60の間でRGBのいずれかが8階調以上変わる画素が150,467あり、逆シークで0の画像に戻った。OFFの初回測定では、モデルが動いても変化は543画素に集中し、画面全体の平均差を使った動作判定で失敗した。保存済み画像で動きを確認し、判定を変化画素数と最大差へ改めた。変更後はON/OFFの両条件で動きと逆シークの全画素一致を確認できた。変更後のWebGPU検証エラーは0件。

既存のElectron回帰5件で、GIの照明・色・消灯からの復帰、天空遮蔽の強度復帰、骨・モーフの直シーク、ルミナスのテクスチャUV、不透明PNGのX室内とAccessory Toonを確認した。全単体テスト1,446件とlintは成功。型検査は既存547件、変更ファイルのエラーと未定義名のcriticalエラーは0件。
