# 未実装 UI 棚卸しメモ 2026-06-20

> 2026-08-14 更新: モデル / カメラ VMD と、選択ボーンの VPD 書き出しはβ実装済み。MMD 本家での読み戻し確認までは「完了」としない。

v0.2 をまとめる前に、現時点で「UI は見えているが中身が未実装 / 仮実装 / 接続が薄い」ものを整理する。

ここでは、単に将来欲しい機能ではなく、ユーザーが触れる導線がすでにある、または最近の UI 方針上すぐ表に出そうなものを優先している。

## 優先度の見方

- `出す`: v0.2 の主要体験として実装して見せたい。
- `隠す`: 実装が追いつかないなら、いったん UI から下げたい。
- `保留`: 実験機能または設計待ち。見せる場合は未実装感を明確にする。

## v0.2 前に決めたいこと

1. **キー編集を主役にする。** 複数キー選択、コピー、ペースト、削除、最小 VMD 書き出しを優先する。
2. **UIだけあるボタンは減らす。** BOX選択、未登録選、反転P、外部親、HDRI は、実装しないなら disabled のまま常時表示しない方がよい。
3. **カメラモードのタイムライン対象を決める。** カメラ、照明、アクセサリをまず入れ、セルフ影と重力は後続でもよい。
4. **実験機能は隠すか明示する。** HDRI / IBL影 / WGSL / Effect layer は、MMD編集本筋と混ぜると v0.2 の印象が散る。
5. **保存 / 読み込み / undo の対象を先に決める。** UI追加だけで止まるものが増えているので、キー系は特に project state と履歴単位までセットで扱う。

### 現在UIとして優先する残件

1. Property（表示 / IK）の登録、ステップ表示、copy / paste、削除、再生・シーク反映
2. 空フレーム挿入 / フレーム列削除の範囲指定UI
3. 上書き確認、未変更時スキップ、複数対象登録、オートキー対象制御
4. 情報欄、下パネル、タイムライン間のModel / Camera / Accessory対象同期

HDRI / IBL Shadows / WGSL実験、汎用3D形式、入力デバイス拡張は、上記のMMD編集導線より低優先またはExperimental扱いを維持する。
