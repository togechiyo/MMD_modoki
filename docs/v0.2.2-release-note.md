# v0.2.2 リリースノート

更新日: 2026-08-14

`v0.2.2` は、MMDデータの書き出し、複数モデル編集、画像・動画出力、FrameGraph表現を拡張するpreviewリリースです。

## 主な追加・改善

### VMD / VPD書き出し

- 選択中モデルのBone / Morph / Propertyキーを標準VMD 0002へ書き出すβ機能を追加
- カメラの中心、回転、距離、FoV、6補間チャンネルを書き出すβ機能を追加
- 選択ボーンの現在ポーズをShift-JIS VPDとして書き出す機能を追加
- Shift-JIS固定長文字列、Bone補間64 bytes、物理ON/OFF、重複キーなどを保存前に厳密検証
- MMD本家でモデルVMD、カメラVMD、VPDの基本読み込みを確認

初期版のVMD出力対象はモデルとカメラです。照明、セルフ影、重力、外部親、物理結果のbakeは出力しません。

### 同一モデルの複数読込

- 読み込んだモデル個体へ安定したinstance IDを付与
- 同じPMXを複数読み込んだ場合も、モーション、選択、外部親、DoF対象を個体ごとに識別
- project保存 / 読込ではIDを優先し、旧projectのpath参照にも互換fallbackを用意
- 同一PMXを3体読み込んだモーション再生をユーザー環境で確認

### PNG / WebM出力

- 単発PNG、PNG連番、WebMを共通のRGBA export surfaceへ統合
- PNG encodingをWeb Workerへ移し、main thread負荷を軽減
- 背景透過PNG / PNG連番と透明プレビューを追加
- 単発PNGへ解像度プリセットと幅・高さ指定を追加
- 3分30秒のエフェクト使用ダンスで、WebM約7分30秒、背景透過PNG連番約6分15秒の実測結果を確認

### MMD編集・互換

- モデル / カメラの外部親を追加し、カメラはMMD互換の回転追従へ対応
- MMD向けモデル描画順と同一平面補正を追加
- PMXモデル情報の確認機能を追加
- UI表示倍率をWindowメニューから変更可能にした
- 外部親と物理の組み合わせ、spring gravity互換を改善

### FrameGraph / 表現

- Motion Blur
- SSGI
- Luminousの安定化
- Aerial Perspective
- Directional Light Shafts / Para Flare
- Floating Light Particles
- Gamma controls

これらは実験的な高負荷エフェクトを含みます。代表環境ではエフェクトなし約45 FPS、Motion Blur / Luminous / SSGIあり約14 FPSという実測でした。

## 既知の制限

- VMD書き出しはβ版。基本読み込みは確認済みだが、すべてのボーン名境界、物理ON/OFF、補間パターンをMMD本家で網羅確認したものではない
- 標準VMDにはモデル / カメラ外部親、照明以外のproject state、重力、物理結果のbakeを保存しない
- 同一モデル複数読込の別モーション・外部親を含むproject round-tripは追加確認を継続する
- 高負荷FrameGraphエフェクトはGPU、解像度、モデル数によってFPSが大きく低下する
- macOS ZIP / DMGは未署名・未notarizeのpreview配布
- Linuxは環境によって `--no-sandbox` が必要
- 通常のTypeScript `typecheck`には既知の非critical errorが残る。リリースでは未定義名参照を検出するcritical gateを使用する
