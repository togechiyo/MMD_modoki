1. V022-061: modelを替えても暗転・終了するP0回帰として、v0.2.0成功 / v0.2.3失敗の配布可能fixture A/Bを最優先で行い、parseからruntime登録までの失敗段階を特定する。ユーザー所有modelは明示的な利用許可がある場合だけ使う。
2. V022-055: 5言語の訳語精度、固定文言、locale再反映、label overflowを一体で修正する。辞書キー一致だけで完了扱いにせず、訳語レビューと各言語GUI確認を分ける。

4. V022-040 / V022-041: 報告されたframe区間を観測点として、再生とframe stepのcamera / bounds / visibility差を記録する。第三者camera dataをそのままfixture化せず、配布可能な最小camera trackへ縮小する。
5. V022-058 / V022-060: 暗転を一括原因扱いせず、morph / effect stack保存と旧projectのDoF OFF遷移を分ける。再現projectが得られない場合は保存schemaと遷移testを先に追加する。
6. V022-004: 同一modelをユーザー領域と上位階層へ置いた場合のresolved pathとtexture相対pathをmacOS logで比較する。
7. V022-059: requestとして保持し、採用する場合だけwindow titleの状態ライフサイクルを設計する。

## 2026-08-30 モデル読込回帰の追加確認

- 対象: [V022-061](./v0.2-feedback.md#v022-061-v023でどのmmdモデルを読み込んでも暗転して終了する)
- 実機所見: v0.2.0で読み込めるmodelがv0.2.3では読み込めず、この状態が継続している。modelを変更しても回避できず、どのmodelでも画面が真っ暗になった後にアプリが終了またはcrashするとの追加確認がある。
- 所有者判断: 個別assetの互換問題ではなくmodel読込経路全体を阻害する可能性があるP0回帰として、早期修正対象に採用する。
- 状態: `fix planned`。まず配布可能fixtureで再現し、v0.2.0〜v0.2.3のA/Bから失敗段階を切り分ける。
- 不足情報: model形式、OS / GPU / backend、読込停止段階、error log、v0.2.1 / v0.2.2での成否。
- 制約: 対象modelは明示的な利用許可なしに探索・読込しない。
