# v0.2.3 リリースノート

更新日: 2026-08-28

`v0.2.3` は、v0.2.2からタイムラインとシーンキー編集を大きく拡張し、アクセサリ編集、画像・動画出力、WebGPU描画互換、UIをまとめて改善したpreviewリリースです。

## v0.2.2からの主な変更

### タイムライン / シーンキー編集

- 照明の色・方向、影欄の表示値、重力の方向・加速度をproject独自のシーンキーとして追加
- 登録、上書き、削除、copy / paste、移動、再生、シーク、project保存、undo / redoを同じ編集経路へ統合
- モデル表示とIK ON/OFFのPropertyキー、空フレーム挿入、フレーム列削除、Auto Key対象切替を追加
- 行・列見出し選択、複数キー選択、反転paste、カテゴリ別選択を整理
- 選択キーの位置・回転・カメラ距離・FoV・表情値を、プレビュー付きで一括補正可能にした
- 別PMXの体格を基準に、センター系・足IKの移動キーを一括補正する機能を追加

詳細は [v0.2.3 タイムライン / シーンキー編集 計画](https://github.com/togechiyo/MMD_modoki/blob/v0.2.3/docs/v0.2.3-timeline-scene-key-editing-plan.md) を参照してください。

### アクセサリ / 変換ツール

- `.x` とOBJをモデルに近い情報欄・下パネルへ統合
- `.x` / OBJの位置、回転、等倍スケールを共通のAccessoryトラックで編集・保存可能にした
- OBJの単一MTLとローカルtexture読込へ試験対応
- 元PMX・元VMD・適用先PMXを指定して別VMDへ保存する、独立したVMDリターゲットツールを追加
- `.x` のalpha分類、逆向き重複面、同一平面、広域表示の安定性を改善

OBJ読込と高度なVMD変換は実験的な初期対応です。複数MTL、すべてのtexture option、複雑な骨格差の自動補正は保証しません。

### 再生 / 画像・動画出力

- seekbarのend handleを停止境界とし、repeat再生と現在フレームの円形markerを追加
- WebM出力へ進捗bar、処理速度、残り時間、cancel操作を追加
- Full HD / QHD / 4Kの標準bitrateを動画サイト向けの目安へ引き上げた
- background export中はowner viewportの描画を一時停止し、macOS WebGPUで重い`.x`と同時に出力した場合の初期化競合を修正
- 出力完了・失敗・cancel後にviewportと操作lockを復帰する経路を整理

### 描画 / モデル表示

- WebGPUの通常shadow経路を復元し、CSM PCFの広域artifactを局所的に回避
- 街・スカイドーム向けにcamera far rangeとreverse depth経路を整理
- 人物を優先して追跡するDoF autofocusを追加
- MMD shader presetの表示名、toon影色、self-shadow presetを整理
- モデル規定のedge幅を無視して全体を均一化する設定を追加
- 物理ボーンは標準でtimelineへ表示し、viewportからは隠すMMD寄せの表示modeへ整理
- PMDなどで使われるBMP texture loaderの依存解決を修正

PBR、SSS、海エフェクト、汎用エフェクトキーは通常UIへ公開せず、内部互換または後続検討として隔離しています。

### プロジェクト / UI / ドキュメント

- 新規projectを現在のprojectを閉じず別windowで開けるようにした
- 汎用UIアクセント、背景選択、再生bar、メニュー構成を整理
- 空のHelpメニュー、内容のないAbout / Keyboard Shortcuts項目を削除し、ログフォルダをToolsへ移動
- 外部開発者向けの技術概要、FAQ、シェーダー / FrameGraphエフェクト一覧を追加・更新

## 既知の制限

- 一部のmacOS配置条件によるtexture白化、モデル依存のtoon・瞳・半透明材質・morph表示は元報告環境で再確認が必要
- 高解像度WebMの画質と、断続的なbackground renderer初期化は報告環境での再確認を継続する
- `.x` / OBJと広域stageの互換は改善したが、すべてのasset構造や材質表現を保証しない
- scene keyのうち影欄・重力はMMD_modoki独自project dataであり、標準VMDへは出力しない
- モデル / カメラVMD書き出しとVMDリターゲットはβまたは試験機能
- macOS ZIP / DMGは未署名・未notarizeのpreview配布
- Linuxは環境によって `--no-sandbox` が必要
- 通常のTypeScript `typecheck`には既知の非critical errorが残るため、リリースでは未定義名参照を検出するcritical gateを使用する

詳細と最新状態は [既知課題](https://github.com/togechiyo/MMD_modoki/blob/main/docs/known-issues.md) と [v0.2.x リリースフィードバック台帳](https://github.com/togechiyo/MMD_modoki/blob/main/docs/v0.2-feedback.md) を参照してください。
