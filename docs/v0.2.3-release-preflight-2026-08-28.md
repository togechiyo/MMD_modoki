## 2026-08-28 リリース結果

- release準備commit `763f20f`を`main`へpushした。
- project ownerの通常運用に合わせ、必須ではない`workflow_dispatch`事前ビルドは行わず、`v0.2.3` tag pushからcanonical buildを開始した。
- GitHub Actions `Build Release Packages` run `#18`で、Windows ZIP / macOS ZIP / macOS arm64 DMG / Linux ZIPの4 build jobがすべて成功した。
- `Publish GitHub Release Assets` jobが成功し、`MMD modoki v0.2.3` prereleaseへ4 assetが添付された。
- 現行workflowはrelease本文を設定しないため、GitHub prerelease本文は空で作成された。公開用本文の正本は[v0.2.3 リリースノート](./v0.2.3-release-note.md)に残す。
