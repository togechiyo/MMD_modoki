## 初動の確認順候補

実装着手はまだ行っていない。MMDの編集・保存・出力への影響から、次の順で再現条件を小さくできるか確認する。

1. 編集値の保持: V022-091 / 092 / 093 / 107。Enter前後のsource値、UI表示値、補間、Undo / Redo、保存再読込を比較する。読込motionを無操作で登録しても値が変わらない条件を先に確かめる。
2. モーション編集・書き出し: V022-089 / 106。削除後と上書きの反転ペースト、別個体へコピーしたmotionのVMD / BVMD出力を配布可能fixtureで比較する。
3. 表示・出力の一致: V022-040 / 041 / 103 / 104 / 105 / 115。viewport、PNG、WebMで同一frame・表示状態・cameraを比較し、Mirror / Luminous / AAの経路を分ける。
4. 長尺出力: V022-072 / 114。Luminousと背景動画のON / OFF、process別メモリ、render / encode / decode時間、分割開始時の物理状態を測る。機材増設だけで改善するとは現段階で判断しない。
5. shortcutの案内・Mac確認、GUI完了通知、残る操作・文書要望を個別に評価する。

既存コードには前後キー移動の`Ctrl＋左右 / 上下`と、選択キー移動の`Alt＋左右`がある（`src/ui-controller.ts`、v0.2.4と現行mainで静的確認）。MacのOption＋左右の成功報告をWindows GUIの再検証やMacのCtrl＋矢印の動作確認に読み替えない。
