# v0.2.4 リリースノート（準備中）

更新日: 2026-09-18

`v0.2.4` は、モデル・モーション形式の追加、プロジェクトと出力の不具合修正、実験的なPBR材質・外部WGSL・ローカルMCP連携を含むpreviewリリースとして準備しています。タグ、配布物、GitHub Releaseはまだ公開していません。

## v0.2.3からの主な変更

### モデル / モーション / 編集

- BPMXモデルとBVMDモデル・カメラモーションの読み込みに対応。PMX / PMDからBPMX、VMDからBVMDへの変換と、編集したモデル・カメラモーションのBVMD書き出しを追加しました。
- 同一PMXを複数読み込んだ場合の個体別編集、モーフの未登録プレビューと登録後の反映、カメラ距離補正を改善しました。
- 選択ボーンを注視する操作を表示メニュー、Fキー、MCPへ追加しました。

形式の対応範囲は [BPMX / BVMD実装ガイド](./bpmx-bvmd-implementation-guide-2026-09-02.md)、モーフの修正は [調査記録](./multiple-morph-registration-investigation-2026-09-17.md) を参照してください。PMX内の日本語名・英語名をUI言語で切り替える対応は今回含めません。

### プロジェクト / 画像・動画出力

- プロジェクトファイルのドラッグ＆ドロップに対応。空のウィンドウではその場で開き、作業中のウィンドウへ落とした場合は新しいウィンドウで開きます。
- カメラ外部親の初期化と保存復元順序を修正し、PNG / WebM出力との整合を改善しました。
- 背景画像・背景動画の表示状態と出力時の同期、アクセサリ表示キーの出力反映、リングパーティクルの動画出力を修正しました。
- DoFをOFFにした場合の暗転、モデルの変形に対する描画範囲、AAのみを有効にしたFrameGraph経路を修正しました。
- モーション削除後に不要なトラックがプロジェクトへ残る経路を修正しました。

元報告のすべてのモデル・環境で解消を確認したという意味ではありません。[カメラ外部親と出力](./issue-26-camera-external-parent-output-2026-09-16.md)、[背景メディアと出力](./issue-26-background-media-output-2026-09-16.md)、[モーション保持](./issue-25-project-motion-retention-2026-09-12.md) に確認範囲を記録しています。

### 描画 / 実験機能

- 設定の実験機能からPBRモードを選べるようにし、通常モードとPBRモードの材質設定を個別に保持します。
- PBR Skin / Skin Faceの強い逆光での白飛び、暗部の持ち上がり、顔の色むらを調整しました。薄い部分の透過を残しつつ、顔全体が光る状態を抑えています。
- 通常モードのSSS Skin / Waxを新規選択UIから外しました。保存済みプロジェクトの材質互換とPBR側のSkin / Skin Face / Waxは維持します。
- ローカルのHDRI環境光、FrameGraphエフェクトの個別ON/OFFと全体停止、SSGI / SSRとモデル輪郭の併用を改善しました。
- 外部WGSL v2の材質割り当てとサンプル・ガイドを追加しました。MME互換機能ではありません。
- 手動で有効にするローカルMCP接続を追加しました。権限設定に応じた編集、ビューポート画像の連続取得、前回のポートが使用中だった場合の再割り当てに対応します。

PBR・WGSL・MCPは実験機能です。SSSの見た目はモデルの形状・大きさにも依存します。[逆光SSSの調整記録](./sss-strong-backlight-2026-09-18.md)、[外部WGSL v2](./external-wgsl-authoring-v2-design-2026-09-16.md)、[MCP実装記録](./mcp-implementation-progress-2026-09-10.md) を参照してください。

### UI / 表示

- 書き出し項目を「VMDモデルモーション書き出し」のように形式名から始まる表記へ整理しました。
- 照明・影・重力パネルのスライダーの高さと余白を揃えました。
- 実験機能設定の翻訳を補い、タイムラインのカメラ・照明・影・重力の固定表示をUI言語へ追従させました。モデル由来のボーン名・モーフ名は維持します。

## 既知の制限 / 継続確認

- macOSのモデル配置先によるテクスチャ白化、モデル読込時の暗転・終了、旧プロジェクトの影・物理、モデル固有の表示不具合は継続確認です。
- 5言語の辞書キーは揃っていますが、一部ダイアログ・通知などに未翻訳文言が残っています。全画面の言語別確認は未完了です。
- エフェクトのタイムラインキー化は開発用opt-inに限定しています。
- 影欄・重力のキーは独自プロジェクトデータで、標準VMDへは出力しません。
- WebM出力は開始時のビューポートの物理状態を引き継ぎます。全モデル・長尺・全エフェクトの組合せを保証するものではありません。
- macOS配布物は未署名・未notarizeです。Linuxは環境によって追加ライブラリや`--no-sandbox`が必要です。

詳細と報告ごとの状態は [既知課題](./known-issues.md)、[フィードバック台帳](./v0.2-feedback.md) を参照してください。
