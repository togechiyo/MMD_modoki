# v0.2.5 リリースノート

## エフェクトにキーを打つ

Effectパネルで調整した効果を、フレームごとに変えられるようになりました。FrameGraphで効果を追加し、フレームを選び、値を変えてカードのひし形を押すとキーを登録できます。同じ種類の効果を複数追加しても、それぞれが独立したキーを持ちます。

- タイムラインでエフェクトキーをコピー、移動、削除でき、Undo・Redoにも対応します。
- キーがある効果は再生位置に合わせて変化します。キーのない効果は再生中も直接調整できます。たとえば、ガンマを時間で変えながらブルームの強さを試せます。
- エフェクトキーはプロジェクトに保存され、PNG・WebM出力に反映されます。効果によってキーで変えられる項目と全フレームに共通の設定が異なります。[効果別の対応範囲](./v0.2.5-release-plan-2026-11-10.md)

## 編集・表示・出力

- 「プロジェクト保存」は現在のファイルへ上書きし、「名前を付けて保存」で別のファイルに保存できます。ファイルメニューからモデル・アクセサリ、背景画像・動画を読み込めます。
- エフェクトのスライダー横に数値入力欄を追加しました。FrameGraphでSSAOとモデルの輪郭線を併用できます。
- モデルのないアクセサリ・カメラのプロジェクトでの再生、タイムライン最下段の行ずれ、ボーンの外部親登録時に補間が線形へ戻る問題を修正しました。
- 音源の終端で再生表示が戻るようになりました。再生終端でもう一度再生すると、先頭または指定した開始位置から再開します。WebM出力が異常終了した場合は編集画面に失敗を表示します。
- WebMを既存の動画へ上書きする場合、出力が完了するまで元の動画を保持します。中断後も同じ保存先に再試行できます。
- ローカルMCPの有効設定が再起動後も保持されます。実行基盤のElectronを45系に更新し、macOSの必要バージョンが13 Ventura以降になりました。

## 継続確認中の報告

真上から見たときの床影の欠落、macOSでモデルなしプロジェクトを保存できない報告、Luminousを使った約8,000フレームの動画が保存されない報告は継続確認中です。長尺出力の失敗原因は特定できていません。[既知課題](./known-issues.md)・[症状別の台帳](./v0.2-feedback.md)
